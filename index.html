Log Studio

어떤 로그를
꾸며볼까요?

대화 로그, 소설, 기록을 꾸미는 편집기 네 가지를 한곳에 모았습니다. 카드를 누르면 해당 편집기로 이동합니다.

ML
01

Memorial Log

마음에 남은 장면과 문장을 티켓·엽서 같은 실물 기록물처럼 한 장으로 남기는 편집기. 계절 테마 템플릿과 이미지 저장을 지원합니다.

문장 아카이브티켓 · 엽서이미지 저장
열기
LC
02

Log Cupcake

대화 로그를 블록 단위(대사·생각·나레이션)로 편집하고 테마·폰트·배경을 꾸미는 도구. 프리셋 저장과 HTML·이미지 내보내기를 지원합니다.

대화 로그테마 프리셋HTML · 이미지
열기
조각
03

조각로그

표지·프로필·본문 카드·꼬리말을 카드 단위로 쌓아 올리는 편집기. 마크다운 서식, 드래그 정렬, 검색·대치, 보관함, HTML 출력을 지원합니다.

카드형 구성마크다운보관함
열기
LD
04

Log Diary

창작물을 웹진처럼 꾸미는 도구. 표지 디자인, 상세한 텍스트 서식, 20종 이상의 테마와 커스텀 테마, JSON 저장·불러오기, 코멘트 섹션을 지원합니다.

웹진 스타일표지 · 테마JSON 저장
열기
