- 기준: `Yuki0117-S2/log_studio`의 `main`, 커밋 `7e13a41ab314f7e7e97776fb6927801d326d90f3`.
- 최신 메인 화면을 바탕으로 07번 카드만 추가했습니다. 로컬에 없던 `html-to-image/`는 이 커밋의 원본 그대로 복사했습니다. 기존 편집기 코드는 덮어쓰지 않았습니다.

- 지원: `<<이름>>`, `**이름**`, `[이름]` 대사, `>>` 캐릭터·`<<` 유저, 문장 속 이름 대사, 강조·속마음, 제목, 정렬, 인용, 상태창, 구분선 3종·여백, 접기, 두 이미지 문법, 주석. 미완성·미지원 문법은 원문으로 남습니다. 다른 편집기의 모든 전용 문법이 완전히 호환되지는 않습니다.
- 기본 글자·배경·강조 색을 조절한 뒤 게시용 HTML에서 **HTML 복사 → 아카 편집기**로 이어갑니다. 열린 편집기의 HTML 입력칸에 붙여넣는 방식이며 기존 편집기의 저장 작업을 덮어쓰지 않습니다. 이미지 변환도 같은 방식입니다.
- 추가 ZIP에서 15종 참고 디자인을 추출했습니다. 포토카드·폴라로이드·체키 기본 출력과 전용 설정, 사진 영역만 PNG 저장을 추가했습니다. 이전 항공우편 프리셋과 이미 작성한 로그는 유지합니다.
- 체키·폴라로이드의 **프레임 포함 한 장 PNG 저장**은 사진과 네모 프레임, 그 안의 대사·서명·날짜·스티커를 함께 저장합니다. 체키는 저장할 때 테이프·기울기·그림자·추가 바깥 여백을 제거해 반듯한 사진 한 장으로 만듭니다. 편집 중인 원본 설정은 바뀌지 않습니다. 폴라로이드는 기존 장식을 유지하며 이미지 선택칸에서 고른 한 장을 저장합니다. 이전 버전에서 만든 체키도 지원합니다.
- 나머지 프리셋의 사진 영역 저장은 현재 비율·위치로 자른 사진을 저장합니다. 외부 이미지 서버가 CORS를 허용하지 않으면 파일 업로드를 안내합니다.
- 프레임 캡처에는 기존 `html-to-image/vendor/html-to-image.js`를 사용하며 기존 이미지 변환 도구의 코드는 수정하지 않습니다. 저장할 카드에 사용된 웹폰트만 PNG에 포함합니다.
- 첨부한 일반 HTML의 본문을 한 입력칸으로 묶고, 원래 문단·대사 스타일과 반복 장면 제목·부제를 보존합니다. 제공된 개인 원문은 배포 파일에 포함하지 않습니다.
- 처음 제공한 HTML을 **검정 헤더 · 긴글 로그** 프리셋으로 등록했습니다. 기본 순서에서 보관함 맨 앞에 표시되며 검정 제목 바·작은 제목, 장면 제목·부제, 이미지 한 장, 전체 원고를 편집할 수 있습니다. 원본 레이아웃과 연한 대사 배경을 유지하고, 기본 내용은 중립적인 예문으로 교체했습니다. 기본 카탈로그는 참고 디자인 15종 + 이 양식 1종입니다. 이전 프리셋과 사용자 사본은 남으므로 실제 보관함 개수는 더 많을 수 있습니다.

## 이번 단계의 범위와 남은 연결

- 원본 HTML의 색상·글꼴·배치를 보존하면서 구현하지 않은 잠금/다음 장 기능과 옵션 설명용 예시는 출력에서 제외합니다. 이미지가 비어 있으면 사진 공간을 숨기므로 예시 썸네일과 높이가 달라질 수 있습니다. 긴 원고와 반복 장면은 원본 서술·대사 스타일로 다시 배치합니다.
- 각 로그에 디자인 사본을 저장합니다. v0.2에서 저장한 기존 로그는 그대로 유지하며, 편집 화면의 ‘교체’에서 같은 프리셋을 선택하면 원고를 보존하고 새 원본 디자인으로 바꿀 수 있습니다. 전용 설정과 여러 사진은 프리셋별로 보관됩니다.
- 일반 HTML의 입력칸 후보는 휴리스틱입니다. 모든 입력 역할의 정확한 자동 인식을 보장하지 않습니다. 스크립트·실행 가능한 요소는 미리보기에서 비활성화하고 원문은 프로젝트에 보존합니다.
- 사용자 HTML의 전역 폰트·크기·줄간격·본문색은 사용자가 해당 속성을 바꿀 때 적용합니다. 원본의 복잡한 배경·중첩 레이아웃을 통합 재편집하는 기능은 아닙니다.
- 원본 HTML 편집은 새 프리셋 사본으로 등록합니다. 이미 만든 로그에 자동 전파하지 않습니다.
- 이미지 파일은 프로젝트에 포함됩니다. 게시판용 공개 이미지 주소를 만드는 업로드 기능은 없습니다. 기존 도구로는 HTML 복사·붙여넣기로 전달합니다.
- 기본 프리셋의 여러 사진·초상을 개별 선택해 교체할 수 있습니다. 실제 이야기 분기, 독자의 SNS 반응 저장, 음원 플레이어는 포함하지 않았습니다.
- 일반 HTML에서 제작한 프리셋의 복잡한 중첩 반복, 여러 이미지별 독립 자르기, 미연결 사용자 입력칸의 임의 재매핑은 후속 확장 대상입니다.
