예제 6개, 도구로 따라 만들기

처음부터 연습: 빌더의 새 문서 → 빈 문서.
바로 바꿔 쓰기: 편집 프로젝트 받기 → 빌더의 프로젝트 열기.

막힐 때 이것부터

  1. 넣을 위치: 상자 선택 → 추가·이동 위치를 ‘안쪽 맨 끝’ 또는 ‘선택 요소 뒤’로 바꿔요.
  2. 사진 가운데: 이미지 선택 → ‘이미지 가운데’. 이미지 크기와 상자 안쪽 여백도 함께 확인해요.
  3. 겹친 요소 선택: 구성 트리에서 선택해요. ‘맨 앞으로·맨 뒤로’는 사진과 글자의 겹치는 순서예요.
  4. 너무 넓은 간격: ‘세로 간격 쉽게 조절’에서 안쪽 여백과 바깥 간격을 나눠 줄여요.
  5. 일부 문장 강조: ‘글자 조각’을 문단 안에 넣고 색·굵기·배경을 바꿔요.
  6. 마지막 확인: 게시 예상에서 접기 확인 → 모바일 확인 → 프로젝트 저장.
이미지·음악·글꼴 주의점

프로필 예제의 재생 장식은 클릭해도 음악이 나오지 않아요. 실제 재생에는 ‘음악 · VIDEO’와 재생 가능한 MP4 주소가 필요해요.

Georgia 글꼴은 일부 숫자가 아래로 내려오는 모양이에요. 반듯한 숫자는 프리텐다드나 Noto Serif KR을 사용하세요.

회전은 현재 게시용 출력에서 제거돼요. 좁은 화면에서는 사진이 더 잘릴 수 있고, 자유 배치가 자동으로 재구성되지는 않아요.

사진은 제공된 캡처 영역 또는 자리 표시예요. 두 번째 겹침 표지는 캡처에 박힌 글자를 피해서 사진 구도가 달라요. 실제 게시용 사진으로 교체해 사용하세요.

프로젝트 받기는 웹사이트·로컬 서버에서 사용해요. 사진은 이 예제 사이트 주소에 연결돼요. 다른 사람에게 줄 때는 배포된 페이지에서 받으세요.
