## 검증 범위 밖

- 실제 아카라이브에 글을 올리거나 저장하지 않았음. 게시 후 필터링·테마·CDN 변화는 후속 확인 필요.
- GitHub 저장소 및 Pages 배포는 변경하지 않았음.
- `file://` 직접 실행은 검사 도구의 URL 보안 정책이 차단해 확인하지 못했음. 실제 기능 검증은 로컬 HTTP에서 수행함. 코드에는 외부 패키지, 모듈 import, 로컬 fetch 등 서버가 필요한 의존성이 없음.
- 동영상·iframe은 편집 중 재생하지 않음. 외부 이미지 서버의 접근 제한이나 만료는 이 편집기가 해결하지 않음.
- 브라우저 저장 공간의 한도와 사생활 보호 설정에 따른 자동 저장 제한은 환경에 따라 다를 수 있음.

사용자가 제공한 가이드·디자인 ZIP과 기존 저장소 파일은 수정하거나 삭제하지 않았음. 개발 중 변경 전 사본은 작업 폴더의 `work/backups/`에 보관함.
